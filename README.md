# BIM4Dproject01

เว็บดูโมเดล **อาคารห้องพัก 4 ชั้น** พร้อมแดชบอร์ด ข้อมูลชิ้นส่วน แผนก่อสร้าง 4D ปริมาณ และต้นทุน ในสไตล์ NPAiRENDER Studio

[เปิดเว็บสาธารณะ](https://netzpj-max.github.io/BIM4Dproject01/#model) · [คลังภาพย่อแบบ](https://netzpj-max.github.io/BIM4Dproject01/#drawings)

## เปิดในเครื่อง

ต้องมี Node.js จากนั้นเปิดโฟลเดอร์นี้และใช้ `npm start` แล้วเข้า <http://127.0.0.1:4198/BIM4Dproject01/#model>

ใช้ `npm test` เพื่อตรวจชุดไฟล์สาธารณะก่อนเผยแพร่ ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

## การเผยแพร่

GitHub Pages ใช้โฟลเดอร์ `docs` บน branch `main` เว็บใช้เส้นทางไฟล์แบบ relative และ hash routing เพื่อรองรับ project Pages

ปุ่ม **แบ่งปัน** คัดลอกลิงก์หน้าปัจจุบัน การแก้ไขข้อมูลบันทึกเฉพาะเบราว์เซอร์ของผู้เข้าชมแต่ละเครื่อง ไม่เปลี่ยนข้อมูลของผู้เข้าชมคนอื่น

## คลังแบบสาธารณะ

- มีเฉพาะภาพย่อ 76 ภาพ ด้านยาวไม่เกิน 320 พิกเซล
- ไม่มีไฟล์แบบ PDF/DWG ภาพแบบขนาดเต็ม ข้อความ OCR หรือข้อความที่ถอดจากแบบใน repository และชุดเว็บนี้
- รายการแบบเก็บเฉพาะรหัสแผ่น หมวด และชื่อประเภทแบบที่จำเป็นต่อการค้นหา
- ไม่ใช้หน้าต่างขยายภาพหรือปุ่มดาวน์โหลดแบบเต็ม
- ควรตรวจ `npm test` ก่อนทุกการเผยแพร่ ห้ามนำโฟลเดอร์แบบหรือชุด ZIP ส่วนตัวเข้ามาใน repo นี้

## สถานะโมเดล

โมเดล R01 มี 6,517 ชิ้น แผนตั้งต้น 33 กิจกรรม อ้างอิงทะเบียนแบบ 61 ไฟล์ / 76 หน้า ยังเป็นโมเดลตรวจทาน ไม่ใช่ Full BIM ที่ตรวจรับครบทุกดีเทล และแผนตั้งต้นไม่ใช่ความคืบหน้าหน้างานจริง

ส่งออก IFC และสำรอง JSON จากข้อมูลในเบราว์เซอร์ได้ การนำเข้าและแก้ไข native ใน Archicad ยังไม่ได้ยืนยันด้วยการเปิดจริง

Three.js และฟอนต์มีไฟล์ใบอนุญาตประกอบใน `docs/vendor` และ `docs/assets`
