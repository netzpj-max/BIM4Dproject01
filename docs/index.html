01 / ARCHICAD 26

IFC สำหรับส่งต่อโมเดล

นำเข้าไฟล์ IFC ด้วย File → Open แล้วเลือก IFC Translator สำหรับการแก้ไข ตั้ง Geometry Conversion เป็น “Construction elements, otherwise Morphs” เพื่อแปลงผนัง เสา คาน พื้นที่รองรับเป็นเครื่องมือ Archicad และชิ้นอื่นเป็น Morph ที่แก้ไขได้

บันทึกเป็น PLN หลังนำเข้า ตรวจชั้น วัสดุ และจำนวนชิ้นส่วนก่อนเริ่มแก้ไข งานระบบและรายละเอียดบางชนิดอาจเป็น Object/Morph ขึ้นกับ translator

คู่มือ Graphisoft: Geometry Conversion ↗

02 / WORKSPACE DATA

แก้ข้อมูลแล้วเก็บต่อได้

การแก้ geometry, ราคา, schedule, progress และ issues บันทึกเฉพาะใน browser ของผู้เข้าชมแต่ละเครื่อง ไม่เปลี่ยนข้อมูลของคนอื่น Export JSON เพื่อสำรองหรือย้ายเครื่อง และนำเข้ากลับได้ รายการ IFC ที่ export จะใช้ geometry / attributes / task assignment ปัจจุบัน

การแก้ไฟล์ใน Archicad ยังไม่ได้เชื่อมกลับเว็บอัตโนมัติ ต้องประสานงานผ่านโมเดลรอบใหม่และตรวจ GlobalId
