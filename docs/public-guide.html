BIM4Dproject01 · เว็บดูโมเดลสาธารณะ

หมุนและเลือกชิ้นส่วนในหน้าโมเดล ดูแผน 4D ในหน้าแผนก่อสร้าง และค้นภาพย่อแบบในคลังแบบ

คลังแบบเผยแพร่เฉพาะภาพย่อขนาดไม่เกิน 320 พิกเซล ไม่มี PDF, DWG, ภาพขนาดเต็ม หรือข้อความที่ถอดจากแบบอยู่ในเว็บนี้

ใช้ปุ่มแบ่งปันเพื่อคัดลอกลิงก์ของหน้าที่กำลังดู ข้อมูลที่แก้ไขบันทึกเฉพาะเบราว์เซอร์ของคุณ ใช้บันทึกชุดข้อมูลเพื่อสำรองเป็น JSON

สามารถส่งออก IFC จากโมเดลปัจจุบันได้ การเปิดแก้ไขในโปรแกรมปลายทางยังต้องตรวจจริง แผน 4D เป็นแผนตั้งต้น และโมเดลยังเป็นงานตรวจทาน
